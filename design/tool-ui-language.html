Subagent · 临时会话

界面不重新设计——就是现有聊天消息列表。唯一差异：标题栏面包屑、底部无 Composer、派遣给 subagent 的 prompt 渲染成用户气泡（外观同用户消息，但不可点编辑）。

交互 — ① 父会话 Agent 卡 → ② 点击进入临时会话 → ③ 消息列表：用户气泡（dispatch prompt，只读）+ assistant 工具/文本 → ④ 无输入框 → ⑤ 点面包屑父标题返回。临时会话不进侧边栏。

v1 — Token / 调用 / 成本

用量页面不是报表系统，
而是同一张纸上的四段文字。

延续工具渲染语言：大数字贴发丝线，不装卡片；趋势图是页面唯一的下沉面板；模型分布是无框行 + 细条；事件明细是发丝线表格。数字一律 JetBrains Mono / tabular-nums，状态仍用绿点红点，不引入第五种彩色。

色彩纪律：图表与分布条一律用 --ink（黑/白）作主色，输入 = 墨色，输出 = 墨色 45% 透明；蓝仅用于「api_call」类型徽标与链接态，绿/红仅表达成功/失败与涨跌。不做彩虹饼图、渐变面积图、立体柱。

范围 · 总览

Segmented control 复用设置页语法；Stat 行是一个带发丝分隔线的浅底长条，不是四张卡片。

规则

落地时按这些约束改 shell，不要把桌面断点 900px 图标轨直接当手机导航。

  1. 01聊天是根。其他都是层：抽屉覆盖、工作区推入、设置推入、更多为底 sheet。
  2. 02空会话沿用「今天想做什么？」；Composer 上浮到视觉中心。一旦弹出 IME，卡片贴在键盘上方，对应桌面 --app-height 在手机上改读 visualViewport.height。
  3. 03桌面 560px 会藏 .composer-add-btn。手机反向：附件入口常显，pill 文字可滑，发送圆钮不挤出卡片。
  4. 04工作区四个 tab 用分段，不再用可拖宽度的多标签条。阅读器标成后续两屏，不在本壳里做 split。
  5. 05会话 ⋯ 常显，替代右键。长按与点 ⋯ 打开同一菜单。

落地映射 — 壳：src/App.tsx 的 .app-shell / TitleBar 在 Android 配置里关掉自定义标题栏；src/styles/modules/app-shell.css 的 .stage 由双列 grid 改单列。Sidebar.tsx → 抽屉（class 仍可复用 .side，改为 overlay）。ChatView.tsx + .chat-topbar → 应用顶栏（菜单 / 标题 / 工作区）。RightPanel.tsx → 全屏路由或 push 页，去掉 usePanelResize。Composer.tsx 保留 .composer-card，覆盖 max-width 与 dock padding。MessageTimeline.tsx 在窄屏 display:none。SettingsView.tsx 的 .settings-side 改分段。窗口：Android 专用 tauri.conf 去掉 minWidth: 1280，本 demo 不改桌面 conf。用量/插件页沿用现有主视图，只换壳，不重画内部语言。

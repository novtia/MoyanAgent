v2 — 物理档案感强化

让这册档案看上去
真的被装订过、盖过章、修订过。

v2 在 v1 的橘色档案骨架上叠加物理档案的证据：上沿装订孔、档号与条形码、贴角照片、双圈五角星印章、方角登记表格、带刻度的仪表、卡片尾部的修订履历与档案脚（建档日期 · 页码）。机密附录升级为火漆印封口件——档案仍是一页纸，但这页纸有了被使用的痕迹。

色彩纪律不变：橘只做档案的纸与墨（--arc-500 #e8722a / --arc-paper / --arc-ink）；绿/红仅表达涨跌与危险；NSFW 保持 --rose-500 单一警示色。数字一律 JetBrains Mono / tabular-nums，姓名与手记用 Noto Serif SC 900 印刷体。
装订与档号
上沿装订孔 + 虚线折边；密级小方章、档号 mono、右侧 CSS 条形码。
表格化登记
现况从散发行改为方角表格：key 列底纹 + 竖分隔线，像履历表栏目。
印章与贴角
双圈五角星「在册档案」斜章；照片位四角加 L 形贴角。
刻度仪表
进度轨加 25/50/75 刻度线，像仪器表盘；涨跌 delta 进 vitals。
修订履历
卡尾新增最近三次变更记录：mono 时间戳 + 字段变化 + 涨跌色。
火漆与档案脚
机密件改火漆印封口；页脚登记建档/更新日期与「第 1 页」。

档案卡 · 完整态

自上而下：装订孔 → 档号条码 → 封面 → 登记表格 → 手记 → 相图 → 关键三格 → 刻度仪表 → 修订履历 → 火漆机密件 → 档案脚。右侧面板宽度约 340–400px。
